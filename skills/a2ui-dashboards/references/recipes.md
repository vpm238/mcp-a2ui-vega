# Chart recipes

_Generated by `tools/verify-recipes.mjs`. Every recipe here was rendered in a
browser against the real dataset before this file was written._

Each one is the `spec` of a `VegaChart`. The component around it is always the
same shape:

```json
{
  "id": "chart_something",
  "component": "VegaChart",
  "data": {
    "path": "/datasets/ticket_sales/rows"
  },
  "filters": [
    {
      "field": "status",
      "op": "eq",
      "value": "paid"
    }
  ],
  "spec": {
    "…": "one of the specs below"
  }
}
```

Columns in this dataset: `ordered_at` and `event_date` (temporal), `show`,
`theatre`, `section`, `channel`, `promo_code`, `customer_segment`, `status`,
`event_time` (nominal), `quantity`, `unit_price`, `gross` (quantitative).

## How far ahead people book

**When:** A field the data does not have. `transform.calculate` makes one — here, days between the order and the performance.

> Vega expressions run in the browser, so no round trip and no new column in the dataset.

```json
{
  "transform": [
    {
      "calculate": "(toDate(datum.event_date) - toDate(datum.ordered_at)) / 86400000",
      "as": "lead_days"
    },
    {
      "filter": "datum.lead_days >= 0 && datum.lead_days < 120"
    }
  ],
  "mark": {
    "type": "bar",
    "cornerRadiusEnd": 2
  },
  "encoding": {
    "x": {
      "field": "lead_days",
      "type": "quantitative",
      "bin": {
        "maxbins": 30
      },
      "title": "Days before the performance"
    },
    "y": {
      "aggregate": "sum",
      "field": "quantity",
      "type": "quantitative",
      "title": "Seats"
    }
  }
}
```

## Gross to date

**When:** Progress towards a total. A `window` transform accumulates without the server computing anything.

```json
{
  "transform": [
    {
      "timeUnit": "yearmonthdate",
      "field": "ordered_at",
      "as": "day"
    },
    {
      "aggregate": [
        {
          "op": "sum",
          "field": "gross",
          "as": "daily"
        }
      ],
      "groupby": [
        "day"
      ]
    },
    {
      "sort": [
        {
          "field": "day"
        }
      ],
      "window": [
        {
          "op": "sum",
          "field": "daily",
          "as": "cumulative"
        }
      ]
    }
  ],
  "mark": {
    "type": "area",
    "line": true,
    "opacity": 0.2,
    "interpolate": "monotone"
  },
  "encoding": {
    "x": {
      "field": "day",
      "type": "temporal",
      "title": null
    },
    "y": {
      "field": "cumulative",
      "type": "quantitative",
      "title": "Cumulative gross"
    }
  }
}
```

## Each show on its own axis

**When:** One pattern per category, where a single chart with ten colours would be unreadable.

> A faceted spec sizes its own children — set `width` and `height` inside the spec, not on the component.

Set `height: 520` on the component.

```json
{
  "mark": {
    "type": "line",
    "interpolate": "monotone"
  },
  "width": 150,
  "height": 70,
  "encoding": {
    "x": {
      "field": "ordered_at",
      "type": "temporal",
      "timeUnit": "yearweek",
      "title": null,
      "axis": {
        "format": "%b"
      }
    },
    "y": {
      "field": "gross",
      "type": "quantitative",
      "aggregate": "sum",
      "title": null
    },
    "facet": {
      "field": "show",
      "type": "nominal",
      "columns": 3,
      "title": null,
      "header": {
        "labelLimit": 130,
        "labelFontSize": 10
      }
    }
  }
}
```
